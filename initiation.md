## 1. Color palette

| Color          | Hex       | Purpose                     |
| -------------- | --------- | --------------------------- |
| Forest Green   | `#183A2D` | Primary brand color         |
| Muted Gold     | `#D6A84B` | Accents, highlights, badges |
| Warm Ivory     | `#F4EFE3` | Warm background sections    |
| White          | `#FFFFFF` | Main background             |
| Main Text      | `#292B27` | Headings and body text      |
| Secondary Text | `#777A73` | Supporting text             |
| Borders        | `#E8E5DC` | Subtle separators           |

Color balance:

- 65–75% white and light backgrounds.
- 15–25% forest green.
- 5–10% gold accents.
- Green should be noticeable but never overwhelming.
- Gold should add elegance, not dominate.

## 2. Overall design style

- Scandinavian minimalism.
- Warm, friendly, premium, and approachable.
- Clean layouts with purposeful whitespace.
- White-dominant design with occasional ivory and green sections.
- No unnecessary decorative elements.

## 3. Typography

- Clean, geometric, modern Persian typography.
- Prioritize readability and comfortable line spacing.
- Use consistent font weights: 400, 500, 600, and 700.
- Support Persian and mixed Persian/English content properly.
- Use Persian digits for customer-facing numbers.
- Final Persian font is still undecided.
- IranSans font

## 4. Layout and spacing

- Consistent spacing system based on 4px increments.
- Balanced whitespace—not excessively empty or crowded.
- Clear visual hierarchy between sections.
- Consistent content widths and alignment.
- Mobile-first approach for the customer-facing website.

## 5. Navigation

- Desktop: Floating, centered navigation container with rounded corners and subtle shadow.
- Mobile: Minimal top navbar with a floating cart.
- Navigation should remain simple and easy to understand.

## 6. Components

- Buttons: Soft, rounded, clear visual hierarchy.
- Cards: Soft-surface style with slightly warm backgrounds.
- Product cards: Consistent image sizes and spacing.
- Cart: Slide-out drawer.
- Checkout: Single-page layout.
- Product details: Dedicated product page.
- Icons: Thin outline style with consistent stroke width.

## 7. Food photography

- Clean studio-style food photography.
- Neutral or white backgrounds.
- Consistent lighting and image treatment.
- Food should be the main visual focus.
- Avoid heavy filters and artificial-looking images.

## 8. Responsive behavior

- Mobile-first customer experience.
- Balanced two-column product grid on mobile.
- Comfortable touch targets.
- Desktop layouts should use available space without becoming excessively wide.
- Admin interface should be desktop-first.

## 9. Persian and RTL rules

- Native RTL layout throughout.
- Correct Persian alignment, punctuation, and typography.
- Persian digits in customer-facing interfaces.
- Handle Latin text, phone numbers, URLs, and technical identifiers correctly using LTR isolation where necessary.

## 10. Interactions and effects

- Subtle animations and transitions.
- Gentle hover effects and slight image zoom.
- Smooth cart drawer transitions.
- Very light shadows.
- Respect reduced-motion preferences.

## 11. Things to avoid

- Glassmorphism.
- Excessive gradients.
- Neon colors and strong glows.
- Heavy shadows.
- Excessive gold.
- Inconsistent typography.
- Overly rounded or decorative components.
- Generic AI-looking layouts.
- Unnecessary whitespace or clutter.

## 12. Tech stack:

 - Nuxt + Vue 3 + TypeScript for the frontend.
 - Django for backend.

The overall visual direction: A clean, Scandinavian-inspired restaurant website with a warm personality, white-dominant layouts, forest-green branding, restrained gold accents, and elegant Persian typography.
